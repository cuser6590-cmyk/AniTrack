# AniTrack 🔴

Your Anime World, All in One Place.

AniTrack is an anime information, watchlist and community platform.

## Planned Features
- Discover and search anime
- Track anime and episode progress
- Anime watch orders
- Upcoming anime and movie updates
- Hindi dub information
- Personal watchlist and statistics
- Optional anime community
- Custom themes
- AI anime assistant (planned)

## Platforms
Android | iOS | Web
